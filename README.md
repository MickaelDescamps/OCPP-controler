# OCPP-controler
OCPP controler  demonstration project

This project implement a demonstration for OCPP 1.6 JSON. You can find all the documentation in the official openchargealliance website: https://openchargealliance.org/my-oca/ocpp/

You have just to download all files from OCPP 1.6 to get description of all messages and general views of operation between the central system (OCPP controler) and the charging point.
